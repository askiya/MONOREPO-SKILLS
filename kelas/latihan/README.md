## Aturan Latihan

1. **Jangan lompat sesi.** Sesi 4 butuh hasil sesi 3.
2. **Kumpulkan bukti kelulusan** setiap sesi. Tanpa bukti, dianggap belum selesai.
3. **Kerjakan tugas mandiri.** Di situ pemahaman terbentuk, bukan saat mengikuti langkah.
4. **Kalau buntu >30 menit**, buka `BANTUAN.md` dan bertanya dengan format lengkap.
5. **Jangan hapus error sebelum dibaca.** Error adalah informasi.
