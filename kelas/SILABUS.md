# Silabus Kelas Vibe Coding Santriverse

## Hasil Akhir

Peserta membangun satu produk fullstack dari ide sampai URL produksi dengan
dokumen lengkap, repo GitHub, staging, domain, database, dan pembayaran opsional.

## Format

16 sesi × 90–120 menit. Setiap sesi: 20% konsep, 60% praktik agent, 20% review.

| Sesi | Materi | Praktik | Output |
|---:|---|---|---|
| 1 | Cara kerja vibe coding | pasang alat + agent | agent bisa edit folder |
| 2 | Git/GitHub | repo, commit, push | repo privat aktif |
| 3 | Ide → PRD | isi template PRD | PRD final |
| 4 | SDLC + scope | fase, gate, out-of-scope | SDLC final |
| 5 | UI system | DESIGN.md + tokens | design spec |
| 6 | Arsitektur | stack, folder, API, env | ARCHITECTURE.md |
| 7 | Task planning | pecah fitur jadi task | TASKS.md |
| 8 | Frontend fondasi | Next.js, UI primitive | app localhost |
| 9 | Frontend fitur | halaman, state, responsive | alur UI lengkap |
| 10 | Backend API | route, validasi, error | API teruji |
| 11 | DB + auth | Prisma, PostgreSQL, role | login + data |
| 12 | Testing | lint, build, unit, manual QA | gate hijau |
| 13 | Deploy gratis | GitHub → Vercel/Render | URL staging |
| 14 | VPS/Coolify | hardening + deploy | URL produksi |
| 15 | Domain + security | DNS, SSL, secret, backup | domain HTTPS |
| 16 | Payment + final demo | webhook sandbox/produksi | transaksi end-to-end |

## Tugas Akhir

Wajib:
- enam dokumen root lengkap,
- repo GitHub rapi tanpa secret,
- frontend + backend + database,
- lint/build/test hijau,
- URL staging dan produksi,
- demo alur utama 5 menit.

Opsional:
- payment aktif,
- admin CRUD,
- email transaksional,
- monitoring.

## Penilaian

| Aspek | Bobot |
|---|---:|
| Kejelasan dokumen | 20% |
| Fungsi produk | 30% |
| UI/responsive/accessibility | 15% |
| Kualitas kode + test | 15% |
| Deploy + security | 15% |
| Demo | 5% |

Produk banyak fitur tapi build merah tidak lulus.
