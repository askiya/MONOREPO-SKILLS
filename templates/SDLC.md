# SDLC — Tahapan Pengembangan

## Fase 1 — Perencanaan
- **Durasi**: ...
- **Input**: ide, riset kompetitor
- **Output**: PRD.md final
- **Selesai kalau**: PRD dibaca ulang dan setiap fitur bisa dijawab "kenapa"

## Fase 2 — Desain & Arsitektur
- **Durasi**: ...
- **Input**: PRD
- **Output**: DESIGN.md, ARCHITECTURE.md, TASKS.md
- **Selesai kalau**: agent bisa merangkum 3 dokumen tanpa kontradiksi

## Fase 3 — Build MVP
- **Durasi**: ...
- **Input**: semua dokumen + TASKS.md
- **Output**: app jalan di localhost, fitur MVP berfungsi
- **Selesai kalau**: fitur F-001 – F-00X berfungsi, `npm run build` sukses

## Fase 4 — Testing
- **Durasi**: ...
- **Input**: app localhost
- **Output**: lint + build + test hijau, bug kritis 0
- **Selesai kalau**: gate testing terpenuhi semua

## Fase 5 — Deploy Staging
- **Durasi**: ...
- **Input**: build hijau
- **Output**: URL publik staging
- **Selesai kalau**: dicoba minimal 3 orang, feedback dicatat

## Fase 6 — Produksi
- **Durasi**: ...
- **Input**: staging teruji
- **Output**: domain sendiri, HTTPS, payment aktif
- **Selesai kalau**: transaksi percobaan berhasil end-to-end
