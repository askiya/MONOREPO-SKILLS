# Kontribusi

1. Fork / buat branch: `docs/<topik-singkat>`.
2. Ikuti aturan di `AGENTS.md`.
3. Satu PR = satu topik. Jangan campur 5 bab.
4. Cek sebelum PR:
   - [ ] Semua perintah sudah dicoba di mesin sendiri
   - [ ] Tidak ada secret / token / password
   - [ ] Link internal tidak mati
   - [ ] Ada checklist di akhir dokumen
5. Judul commit: `docs(<topik>): <ringkasan>`.
